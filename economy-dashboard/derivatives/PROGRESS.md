## 4. 주의·알려진 한계
- KRX 화면은 "20분 지연 정보"다. 장마감 후에 조회한다.
- 선물 시세 CSV는 거래일의 `(주간)` 줄만 쓴다. 거래일 칸을 해당 날짜로 먼저 맞춘다.
- 투자자별·프로그램매매 CSV에는 날짜와 시장 정보가 없다. 조회기간을 거래일 하루, 시장은 KOSPI로 받는다.
- 주식 투자자별 CSV와 파생 투자자별 CSV는 헤더가 같다. `기타외국인` 줄이 있으면 주식 파일로 구분한다.
- KRX CSV는 EUC-KR이다. 화면이 자동으로 인코딩을 처리한다.
- ECOS 환율 CSV는 날짜가 열(2026/10/16 형식)로 펼쳐져 있고 숫자에 쉼표가 있어 전용 읽기를 쓴다. 거래일 열이 없거나 종가가 비어 있으면(장마감 전) 안내 문구만 나오고 값은 넣지 않는다.
- 네이버 추출 전에 `KRX`/`NXT` 버튼을 확인한다(NXT 값이 섞이면 KRX 값과 크게 다르다). 일자별 표의 맨 위 줄은 오늘(장중)이다.
- 판독은 과거 기록이 쌓여야 정확해진다(상대 강도, 5일·20일 누적). 10일 미만이면 "비교 데이터 부족"이 나온다.

## 5. 매일 작업 순서
1. 화면에서 거래일을 맞추고 모드를 "장마감 Final Review"로 둔다.
2. KRX(data.krx.co.kr)에서 CSV 5종을 저장한다. 메뉴 경로와 조회 조건은 화면의 "5. 원자료 열기" 카드 ①~⑤.
3. "A. CSV/TXT 파일"에서 KRX 5종과 ECOS 환율 CSV를 한꺼번에 선택해 불러온다(Ctrl/Shift 다중 선택. 하나씩 불러도 값이 합쳐진다). 인식 못 한 파일은 이름이 안내된다.
4. ECOS(ecos.bok.or.kr)에서 '원화의 대미달러, 원화의 대위안/대엔 환율'을 일 단위로 조회해 CSV로 받고 같은 칸으로 불러온다(또는 직접 입력).
5. "확인 후 판독하기"를 누른다.
6. "오늘 판독 JSON 저장"으로 저장한 파일을 AI에게 전달해 `data/records.json`에 추가한다.
7. 화면을 새로 열어 배지의 날짜가 오늘로 바뀌었는지 확인한다.
