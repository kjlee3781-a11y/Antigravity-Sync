파생시장 관제실 Portable v0.2 — 사용안내
작성일: 2026-10-13

[목적]
- 대부분 장마감 Final Review, 가끔 장중 Quick Check
- 현물-선물 엇갈림의 의미를 먼저 보고 위험선호/위험회피와의 부합 정도를 보조적으로 판단
- 예측이나 자동매매가 아니라 관측 사실 → 후보 해석 → 근거 → 반대근거 → 다음 확인사항의 순서로 사용

[새 PC에서 실행]
1. ZIP 압축을 풉니다.
2. '실행_파생시장관제실.bat' 또는 'index.html'을 더블클릭합니다.
3. Edge/Chrome 등 최신 브라우저만 있으면 됩니다.
4. Python, Node.js, 별도 DB, 서버, 로그인은 필요 없습니다.

[데이터 넣기]
- CSV/TXT/TSV 파일 선택
- 또는 표를 복사해 붙여넣기
- 또는 인식 결과를 직접 수정
- .xlsx는 이 버전에서 직접 읽지 않습니다. CSV로 저장하거나 표를 복사해 붙여넣으세요.
- 실제 KRX/ECOS 원자료 형식별 자동 어댑터는 실제 샘플 5거래일을 대조하면서 추가하는 것이 다음 단계입니다.

[판독 원칙]
- 규칙엔진이 후보를 높음/중간/낮음으로 분류합니다.
- AI는 판정을 바꾸지 않고 필요할 때 설명만 담당합니다.
- 'AI 해설용 프롬프트 복사' 버튼을 이용해 ChatGPT 등에 붙여넣을 수 있습니다.
- 선물 순매수는 실제 순롱 잔고나 신규 롱을 의미하지 않습니다.
- 시장 전체 OI는 외국인 OI가 아닙니다.
- 프로그램매매는 현물의 부분집합이므로 현물 순매매와 합산하지 않습니다.

[저장]
- 장마감 Final Review 최근 20거래일만 브라우저에 유지합니다.
- 중요일은 사용자가 승인한 날만 별도 아카이브에 남깁니다.
- 브라우저 localStorage는 편의기능입니다.
- '전체 백업 JSON 저장'으로 만든 JSON 파일을 공식 사용자 데이터로 취급하는 것을 권합니다.
- 다른 PC에서는 같은 프로그램을 연 뒤 '백업 JSON 불러오기'로 복원합니다.

[현재 v0.2 범위]
- Portable 단일 HTML + Vanilla JS
- 장중/장마감 2단 모드
- 표준 CSV/넓은 표/키-값 표 인식
- 수동 수정
- 최근 20일
- 후보 해석 6종
- 상대강도(과거 표본이 있을 때)
- 중요일 후보
- 중요일 사용자 승인 저장
- D+1/D+3/D+5 사후 확인
- 유사한 과거 조합 제시
- 원자료 링크 편집
- JSON 백업/복원
- AI 해설 프롬프트 복사
