# 파생시장 관제실 Portable v0.2 구현기록

- 작성일: 2026-10-13
- 상태: Portable MVP
- 기반: 기존 `파생시장 관제실 v0.1`의 보수적 판독 원칙을 유지하면서, 새 PC 무설치 실행을 위해 브라우저 기반 단일 HTML + Vanilla JS 구조로 전환
- 배포: ZIP 압축 해제 → `실행_파생시장관제실.bat` 또는 `index.html`

## 확정된 운영 원칙
1. 대부분 장마감 Final Review, 가끔 장중 Quick Check
2. 1차 목적은 현물-선물 엇갈림 해석, 2차는 위험선호/위험회피, 보조는 3·5·20일 지속성
3. 단일 상태 단정 대신 후보 순위 + 근거 + 반대근거
4. 1군 입력: 외국인 현물/선물, 프로그램, KOSPI200, 대표월물, USD/KRW
5. 2군: OI/Basis, 3군 옵션은 후속
6. 원자료 업로드/붙여넣기 → 자동 표준화 → 사용자 확인 → 판독
7. 최근 20거래일만 유지, 중요일만 장기 보관
8. 장중은 잠정치/간단 판독, 장마감은 공식자료 우선/최종 판독
9. 점수화 금지. 높음/중간/낮음 + 데이터 완성도
10. 규칙엔진이 판정하고 AI는 설명만
11. AI 해설은 필요할 때만
12. 다음 거래일 확인사항 제공
13. 장중→종가 변화가 크면 중요일 후보
14. 유사일은 비교용이며 수익률 예측으로 사용하지 않음
15. 중요일 D+1/D+3/D+5 사후 확인
16. 규칙은 버전 관리하며 변경은 사용자 승인 후
17. 새 PC에서 Python/Node/DB/서버 없이 실행
