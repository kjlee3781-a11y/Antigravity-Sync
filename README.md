# Antigravity-Sync 폴더 안내

이 저장소는 웹에서 바로 여는 프로그램(HTML)을 모아 두는 곳입니다.
메인 주소 `https://kjlee3781-a11y.github.io/Antigravity-Sync/` 에서 카드로 골라 엽니다.

| 폴더 | 내용 | 열기 주소 끝부분 |
|---|---|---|
| `economy-dashboard/` | 경제·시장 관제시스템 Phase 2 v0.8 | `/economy-dashboard/` |

## 규칙
- AI는 작업 전에 `AGENTS.md`를 읽고, 프로그램 폴더의 `PROGRESS.md`(현재 상태·결정·할 일)를 먼저 확인한다. 끝나면 `PROGRESS.md`를 갱신한다.
- 프로그램 1개 = 폴더 1개. 서로의 파일을 섞지 않는다.
- 각 폴더의 시작 파일 이름은 `index.html`.
- 맨 위(루트)의 `index.html`은 프로그램 목록 화면이다.
- 프로그램의 날짜별 기록은 그 프로그램 폴더 안의 `data/` 폴더에 둔다. (예: `economy-dashboard/derivatives/data/records.json`)

## 파일명 규칙 (GitHub 안에서만 적용)
- **주소로 열리는 폴더·HTML**: 영문 소문자와 `-`, 이름 고정. 날짜나 버전 번호를 붙이지 않는다. (주소가 바뀌면 링크가 깨진다)
- **기록 데이터**: 프로그램 폴더 안 `data/`, 날짜는 `2026-10-14` 형식.
- **문서(md, txt)**: 한글 허용, `프로그램명_문서종류` 형식, 날짜를 붙이지 않는다. (작성일은 본문에, 이력은 커밋 기록에)
- **예외**: AI가 읽는 입구 문서(`AGENTS.md`, `README.md`, `PROGRESS.md`)는 영문 고정 이름, 내용은 한글. (한글 파일명은 주소로 읽을 때 깨질 수 있다)
- **버전 관리**: 파일명이 아니라 커밋 메시지, 화면 안 버전 표기, 문서의 변경기록으로 한다.
- **커밋 메시지**: `프로그램명: 변경 내용` 한 줄, 끝에 작성 주체를 붙인다. (`[클로1]` `[클로2]` `[챗지피티]` `[코덱스]` `[제미나이]` `[안티그래비티]` `[박사님]`)
- 이 저장소 밖(Drive 등)에서는 기존 `_claude_날짜(n)` 규칙을 그대로 쓴다.
- 파일 삭제는 박사님 승인 후에만 한다. 이름 변경은 링크가 깨지지 않는지 먼저 확인한다.
